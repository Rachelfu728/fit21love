# 🌿 Fit21 · 每日感恩生命樹 (Gratitude Tree of Life)

> **「以 21 天的微光，長成一棵安定心靈的大樹。」**  
> 一個以日系無印美學打造的極簡感恩日記 Web App。支援手機 PWA「加入主畫面」、自動離線儲存，以及長成大樹時的 LINE 群一鍵報喜分享。

---

## ✨ 核心特色

1. **極簡純粹：1 件感恩 = 1 片葉子**
   - 拒絕繁瑣作業感，無論何時想到一件小確幸，寫下一句話，樹梢就精準萌發 1 片帶號碼的彩色葉片。
2. **21 件長成大樹（21-Day Habit Loop）**
   - 滿 21 葉蔚然成蔭，成就感爆棚；滿 42 葉解鎖第 2 棵樹（粉櫻樹）、滿 63 葉解鎖第 3 棵樹（金黃銀杏），逐步耕耘出你的專屬「心靈森林」。
3. **社群正向飛輪：一鍵複製 LINE 報喜文字**
   - 滿 21 件大樹長成時，一鍵複製精美排版的溫暖文案到剪貼簿，直接在 LINE 群組與好友、伴侶或社群互相激勵。
4. **極致隱私與離線可用（Local-First & PWA）**
   - 數據 100% 儲存在使用者本地裝置（LocalStorage），完全無伺服器窺探隱私。
   - 支援手機（iOS / Android）加入主畫面，打開即是獨立 App，秒速載入、無網可用。
5. **日系和紙與一筆畫愛心美學（MUJI Zen Aesthetic）**
   - 柔和的米白和紙質地、沉靜深苔綠與木質調，營造靜心、放鬆的治癒氛圍。

## 🚀 30 秒免費部署到 GitHub Pages

此專案為純前端零依賴架構，不需要任何建置步驟，即可直接發布：

1. **建立 GitHub 儲存庫**：
   - 在 GitHub 上點擊 **New repository**，命名為 `fit21`。
2. **推送代碼**：
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of Fit21 Gratitude Tree"
   git branch -M main
   git remote add origin https://github.com/<你的使用者名稱>/fit21.git
   git push -u origin main
   ```
3. **開啟 GitHub Pages**：
   - 進入儲存庫的 **Settings** -> **Pages**。
   - 在 **Build and deployment** 下的 **Branch** 選擇 `main` 分支、資料夾選擇 `/ (root)`。
   - 點擊 **Save**，約 1 分鐘後即可獲得免費上線網址（例如：`https://<你的帳號>.github.io/fit21/`）！

## 📱 手機使用教學（加入主畫面）

- **iPhone (Safari)**：打開網址 ➔ 點擊底部「分享」按鈕 ➔ 選擇「加入主畫面 ➕」。
- **Android (Chrome)**：打開網址 ➔ 點擊右上角「⋮」 ➔ 選擇「安裝應用程式」或「新增至主畫面」。

安裝後桌面會出現簡約質感的 Fit21 愛心圖示，隨時點開記錄每天的溫暖時刻！
